# 🛒 E-Commerce Sales Analysis Dashboard


---
An e-commerce business wants to understand which product categories, regions, and time periods drive the most revenue and profit — and where losses are occurring due to high discounts or returns.

## 🎯 Objectives
- Identify top-performing product categories and regions
- Analyze monthly revenue trends and seasonal patterns
- Measure the impact of discounts on profit margins
- Build an interactive KPI dashboard for business stakeholders

## 📊 Key KPIs Tracked
| Metric | Value |
|---|---|
| Total Revenue | ₹38+ Crore |
| Total Orders | 50,000 |
| Avg Order Value | ₹7,600+ |
| Overall Profit Margin | ~28% |
| Return Rate | ~7% |

## 💡 Key Insights
1. **Electronics** drives ~35% of total revenue — highest priority category
2. **North region** is the top revenue contributor
3. **October–December** shows peak sales — ideal for campaigns
4. Higher discounts (>20%) significantly reduce profit margins
5. Books & Beauty have lowest margins — pricing review recommended

## 🗂️ Project Structure
```
ecommerce_sales_analysis/
├── analysis.py          # Full EDA, data cleaning, KPI calculations
```

## 🚀 How to Run
```bash
pip install pandas numpy matplotlib seaborn plotly streamlit
python analysis.py              # Run EDA & save charts
streamlit run streamlit_app.py  # Launch interactive dashboard
```
