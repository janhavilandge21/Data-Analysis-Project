# 🌱 Plant Disease Analysis Dashboard

An interactive and intelligent dashboard for analyzing, detecting, and visualizing plant diseases using environmental data and image inputs. This project is built with **Python, Streamlit, Pandas, Plotly**, and **Computer Vision** libraries.

---

## 🚀 Project Overview

The Plant Disease Analysis Dashboard offers real-time monitoring and analysis of plant diseases. It helps farmers, agronomists, and researchers understand the spread and severity of various plant diseases and the role of environmental factors like temperature, humidity, and rainfall.

---

## 📌 Features

- 📊 **Dashboard Overview**
 
  View key plant health metrics, distribution of diseases, plant-wise stats, and environmental impact visualizations.

- 🔍 **Disease Detection (Image-Based)**
   
  Upload plant leaf/stem images to simulate AI-based disease prediction with confidence levels.

- 📈 **Trend Analysis**
   
  Analyze disease spread trends, correlation with climate conditions, and treatment effectiveness.

- 🌍 **Geographic Distribution**
 
  Interactive map showing regional disease hotspots and related statistics.

- 📋 **Data Management**
   
  Filter, view, and export plant disease data in CSV and Excel formats. Check data quality with built-in metrics.

Install the dependencies:

pip install -r requirements.txt

Run the Streamlit app:

streamlit run p.py


📷 Image Upload Simulation

This dashboard includes a simulated disease detection model using image confidence scores. You can upload plant images (leaf/stem) in .png, .jpg, or .jpeg formats to see predictions and severity levels.
