# 🏏 IPL Data Analysis
📌 Project Overview

This project analyzes IPL player performance, salaries, and game statistics across multiple seasons using NumPy and Matplotlib.
It highlights salary trends, points scored, and player efficiency metrics to understand player contributions over time.

📂 Dataset / Input

Seasons → 2015 - 2024

Players → Sachin, Rahul, Smith, Sami, Pollard, Morris, Samson, Dhoni, Kohli, Sky

Data Tracked:

Salary per season

Games played

Points scored

🛠️ Technologies Used

Python 3

NumPy → Data storage & calculations

Matplotlib → Data visualization

🔎 Key Analysis Steps

Data Preparation

Created salary, games, and points matrices for each player.

Mapped seasons and players using dictionaries.

Player Statistics

Salary per game = Salary ÷ Games

Performance comparison across seasons.

Visualization

Line plots for salary trends.

Multi-player salary comparisons.

Legends & customized plots (colors, markers, labels).

📊 Insights & Findings

Salary Growth → Most players’ salaries increased significantly over time.

Consistency → Players like Sachin and Rahul showed steady salaries & performance.

High Variations → Some players (e.g., Dhoni, Kohli) had sharp rises/drops in salary or games.

Efficiency Metric → Salary per game reveals hidden insights about cost-effectiveness.

🚀 How to Run

Install dependencies:

pip install numpy matplotlib


Run the Jupyter Notebook:
